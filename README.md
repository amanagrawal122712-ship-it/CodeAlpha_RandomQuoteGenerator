
# CodeAlpha Random Quote Generator

A stylish and interactive web application that displays random inspirational quotes.

## Features

- Displays a random quote when the app opens
- New Quote button to generate another quote
- Shows quote text and author name
- Previous Quote navigation
- Copy Quote functionality
- Responsive dark-purple user interface
- Multiple quote categories

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Clipboard API

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your web browser.

## Project Structure

- index.html — Application structure
- style.css — Design and responsive layout
- script.js — Quotes and application functionality
